Slide 06 / Security Architecture

Enterprise Security & Authentication

🔐 JWT Authentication

Stateless authentication using standard JWT tokens signed with HMAC-SHA512. Tokens injected into HTTP Authorization: Bearer headers.

🛡️ BCrypt Hashing

Passwords hashed with BCrypt strength 10 before saving to PostgreSQL. Zero plain-text credentials stored.

👥 Role-Based Access Control

Differentiates CUSTOMER and ADMIN roles using Spring Security @PreAuthorize("hasRole('ADMIN')") annotations.

💾 Database Schema Versioning

Flyway database migration engine automates table creation and seed data execution reliably across environments.
